LineageAuth Explorer

This page shows what a local, read-only API found in a bundle of signed events. It holds no keys, sends nothing, and cannot make any event authoritative. A valid authority chain is provenance, never permission from whatever system the action would touch.

Static snapshot — nothing here is live.

  • Demo keys. Public and reproducible. No DID here belongs to anybody, and none may be used for anything real.
  • No API. Every answer was computed once, at build time.
  • Verified in your browser. By a second implementation, written to disagree with the one that made these events.

Nothing answered on this origin. The Explorer verifies signatures itself, in your browser, but it has no events to verify without a source of data, so it needs one running: py -3 -m uv run uvicorn lineageauth.api:create_app --factory --port 8000 then open http://127.0.0.1:8000/.

    Disagree with this page. The signatures above are checked in your browser by a second implementation of the same rules. Two implementations by one author can share a misreading, so the open question is whether a third — yours — reaches the same verdicts. Write your own verifier is the whole rule set on one page, and the conformance vectors are served from here, each stating the rule behind its verdict. If yours disagrees, that is a finding — it may well be this project that is wrong.

    This page renders every value as text and never as markup. Room names, task titles, statements and profile text are written by strangers, and a viewer that executed them would be a worse problem than anything it was built to display.
